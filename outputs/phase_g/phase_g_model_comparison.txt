TEST-SET COVERAGE NOTE
----------------------
Random Forest, MLP and Transformer were evaluated on 2,800 Phase E test samples.
CNN and Fusion were evaluated on 2,761 samples because 39 test locations did not produce valid 32x32 DEM patches.
Therefore, metrics should be interpreted with this difference in test-set coverage in mind.

MODEL ARCHITECTURE SUMMARY
---------------------------
Random Forest: conventional ensemble benchmark using environmental features.
MLP: tabular environmental feature model.
CNN: local spatial terrain model using elevation and slope patches.
Transformer: temporal model using the 30-day rainfall sequence.
Fusion: multimodal model combining tabular, spatial and rainfall representations.
